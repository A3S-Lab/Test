# Homepage surface brief

- Scope: the Rspress homepage and its responsive first-party documentation chrome.
- Visitor mode: Persuade, with a real Operate moment inside the Test Kit stage.
- Audience: coding-agent users and frontend engineers evaluating whether A3S Test can understand a rendered interface and preserve inspectable evidence.
- Job: make the page-context mechanism legible in the first viewport, let the visitor open the real review overlay, then offer a one-command install or documentation path.
- Primary action: start the local Test Kit experience. Secondary actions: read the guide and copy a platform installer.
- Proof: real `A3STestKit`, `A3STestBoundary`, `A3SReviewOverlay`, and revisioned geometry from the page-context bridge; submissions remain in memory and contact no repair endpoint.
- Constraints: Chinese is default with English parity; archived versions pin installers; light A3S Cloud family; keyboard and mobile navigation stay correct; no invented repair outcome, customer, metric, or unsupported capability.

## Chosen direction

- Approved comp: `.impeccable/mocks/comp-b-wide-evidence-stage.png`.
- Composition: a shallow promise band above one broad evidence stage. Rendered page occupies about 56%, live context about 24%, and review/evidence about 20%; a slim installer rail closes the viewport.
- Memorable moment: the visitor opens the real review layer over the highlighted order action, while the adjacent inspector reports that rendered element's current revision, semantic identity, source boundary, locator, and geometry.
