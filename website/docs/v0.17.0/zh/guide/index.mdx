# 跑通第一个 Web 测试

这份指南从一个正在运行的本地页面开始。完成后，你会得到一份可复查的会话记录，其中包含目标、每次观察、实际动作、截图和终态报告。路径稳定后，可以继续把它写成 ACL 回归套件。

## 先选对入口

| 你现在要完成的事             | 从这里开始                               |
| ---------------------------- | ---------------------------------------- |
| 探索陌生页面或复现一个问题   | 继续本页，使用持久 Agent 会话            |
| 重复运行已经明确的流程       | [探索与回归工作流](./workflows.mdx)      |

下面的示例假设产品已经运行在 `http://127.0.0.1:3000/checkout`，并且确认页有一个可观察的标题。请把 URL、目标和成功条件换成当前项目的真实状态。

## 安装 CLI 与 Agent Skill

macOS 或 Linux

```bash
curl -fsSL https://github.com/A3S-Lab/Test/releases/latest/download/install.sh | sh
```

Windows PowerShell

```powershell
& ([scriptblock]::Create((irm 'https://github.com/A3S-Lab/Test/releases/latest/download/install.ps1')))
```

安装器会下载当前平台的 CLI，校验 SHA-256，并为检测到的编码 Agent 安装同版本 Skill。需要固定版本、Agent 或目标目录时，请查看[安装指南](./installation.mdx)。

## 1. 启动持久会话

先启动本地产品，再声明测试目标和可以从页面确认的成功条件。

```bash
a3s-test agent start http://127.0.0.1:3000/checkout \
  --session checkout \
  --goal "Complete checkout with the fixture account" \
  --success "The confirmation heading is visible" \
  --json
```

会话会保留浏览器、策略边界和追加式事件记录，直到显式完成、取消或超时。

## 2. 读取最新观察

```bash
a3s-test agent observe --session checkout --interactive --json
```

响应会带回新的 `observation_id` 和当前可操作语义引用。

```text
observation_id: 1
@e1 [button] Continue
```

页面嵌入 Test Kit 后，同一次观察还可以包含 `@cN` 引用与 Page Context，其中包括组件归属、首选定位器和多坐标空间几何。`@eN` 与 `@cN` 都只在生成它们的观察中有效。

## 3. 执行一个受限动作

把动作绑定到刚才的观察。

```bash
a3s-test agent click @e1 \
  --session checkout \
  --observation 1 \
  --json
```

A3S Test 会在驱动执行前检查动作 Schema、会话能力、策略和观察修订。页面状态一旦变化，旧引用立即失效。继续操作前必须再次运行 `agent observe`。

## 4. 保存证据并结束会话

确认目标状态已经出现后，保存截图并写入终态报告。

```bash
a3s-test agent screenshot screenshots/confirmation.png \
  --session checkout \
  --json

a3s-test agent finish \
  --session checkout \
  --status passed \
  --summary "Checkout completed and confirmation was observed" \
  --json
```

每个工作区保留追加式记录。

```text
.a3s-test/agent-sessions/checkout/
├── session.json
├── events.jsonl
├── report.json
└── artifacts/
    └── screenshots/confirmation.png
```

`events.jsonl` 说明每一步发生了什么，`report.json` 保存终态与摘要，`artifacts/` 只包含这次会话拥有的证据文件。

## 5. 把稳定路径写成回归

Agent 会话适合发现路径。动作、等待和成功条件已经明确后，把它们写成 ACL，再用 `a3s-test check` 做静态准入，用 `a3s-test run` 在本地或 CI 重复执行。完整示例见[探索与回归工作流](./workflows.mdx)。
